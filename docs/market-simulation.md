# DEFINN Market Simulation (Phase 16)

## Overview

Phase 16 replaces the simplistic DEMO1/DEMO2/DEMO3 random walk with a **curated universe of real NSE-listed Indian equities** simulated locally by DEFINN.

**Important:** Real listed security identities do **not** mean real exchange execution. DEFINN does not send orders to NSE/BSE and does not use real money.

## Data policy

| Source | Meaning |
| --- | --- |
| `HISTORICAL_IMPORT` | CSV-imported reference OHLCV data |
| `SIMULATION` | DEFINN-generated future/session prices |

- No continuous NSE/BSE web scraping
- Historical CSV import for academic reference charts
- All live movement is generated by the simulation engine

## Stock universe

~29 NSE equities (RELIANCE, TCS, INFY, HDFCBANK, …) seeded via:

```bash
npm run market:seed-universe
```

Legacy DEMO1/DEMO2/DEMO3 remain in the database as **inactive** for historical demo trades.

## Historical import

```bash
npm run market:import fixtures/market-data-sample.csv
npm run market:import path/to/data.csv --dry-run
```

CSV columns: `date,symbol,exchange,open,high,low,close,volume`

## Simulation model

Short-term log return per stock:

```
r_i = alpha + beta_i * marketReturn + sectorBeta_i * sectorReturn
      + momentum + meanReversion + volatility * shock
price_{t+1} = price_t * exp(r_i)
```

Features:

- Market regime (BULL / BEAR / NEUTRAL / HIGH_VOLATILITY)
- Sector-correlated shocks (IT, BANKING, ENERGY, …)
- Volatility regimes with clustering
- Mild momentum and mean reversion
- OHLCV candle generation with volume linked to activity
- Seeded PRNG for reproducible tests

## Architecture

```
MarketSimulationEngine (singleton, in-memory)
    ↓ periodic tick
PostgreSQL Stock.currentPrice + PriceHistory (SIMULATED)
    ↓ on trade submit
syncOnChainStockPrice() → Stock.sol.updateStockPrice()
    ↓ user signs
Stock.sol buy()/sell() at synced execution price
```

## Controls (development)

`POST /api/market/simulation/control` when `ALLOW_SIMULATION_CONTROL=true`:

- `start`, `pause`, `reset`, `speed`

`GET /api/market/status` — regime, sentiment, simulation clock.

## Environment

| Variable | Description |
| --- | --- |
| `MARKET_SIMULATION_AUTO_START` | Auto-start engine on server boot |
| `ALLOW_SIMULATION_CONTROL` | Enable dev simulation API |
| `BLOCKCHAIN_ADMIN_PRIVATE_KEY` | Optional admin signer for price sync |

## Limitations

- Reference seed prices are not live market quotes
- Simulation betas/sectors are academic parameters
- Single server-side engine (not per-browser)
- On-chain price sync requires Anvil + admin key
- Not suitable for investment decisions
